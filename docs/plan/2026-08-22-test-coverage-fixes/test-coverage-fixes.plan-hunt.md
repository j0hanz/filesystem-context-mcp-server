  (`node --import tsx src/index.ts`). Whether it connects cannot be settled by
  read-only checks — only by running. The plan's [STOP](test-coverage-fixes.plan.md#stop)
  already names this ("subprocess does not connect within ~10s … report the
  subprocess's stdout/stderr rather than retrying"). Appropriate; no change.
- **Step 1 Notes wording.** The plan's Notes says validation becomes
  "equivalent-or-looser." True for **inputs** (a charset regex is looser than
  true base64url decoding). For **outputs** it is the opposite: AJV _ignores_
  unknown `format` keywords (the old behavior, no enforcement) but _enforces_
  `pattern` (the new behavior). Server outputs always satisfy both
  (`createHash('sha256').digest('hex')` → 64 lowercase hex; cursors are
  base64url → `[A-Za-z0-9_-]+`), so no test breaks. Cosmetic imprecision in the
  Notes; not a dead step.
