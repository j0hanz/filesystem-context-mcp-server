# Implementation Plan: Finish Phase 2 — Legacy Removal & Folder Consolidation

## 1. Goal

The migration to the new `defineTool` engine and multi-block `ContentBlock[]` responses landed and tests pass, but the legacy 5-layer tool pipeline, the `server/`, `resources/`, and `schemas/` folders, and 18 verb-mixed tool names still exist alongside their consolidated replacements. This plan removes the dead code, collapses the folders into single-file modules per [src/server.ts](src/server.ts), [src/resources.ts](src/resources.ts), and [src/schema.ts](src/schema.ts), and renames/merges tools to the 16-tool verb-first inventory. Success is observed by `npm run tasks` remaining green after each phase and by the legacy files no longer existing on disk.

## Rollback

This refactor is destructive (file deletions and tool renames). Each phase is a single git commit; rollback is `git revert <phase-sha>` in reverse order. Tag the pre-refactor commit (`pre-phase2-cleanup`) before starting PHASE-001. PHASE-005 also requires reverting the published server.json/README diff and bumping the package version downward only via a fresh patch release, not a rewrite.
